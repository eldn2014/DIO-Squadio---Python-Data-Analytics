Comandos Simples git
  • Git Clone: Clona um repositorio que esta na nuvem para a sua máquina
  • Git Commit: Grava as alterações que você fez no repositorio clonado na sua máquina
  • Git Pull: Puxa para o repositorio que esta na sua máquina, uma versão atualizada do repositorio que esta na nuvem e atualiza o seu repositorio
  • Git Push: Envia para o repositorio na nuvem o commit que você fez.
